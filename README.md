# Reading Time Badge

A tiny WordPress plugin that shows the estimated reading time of a post.

## Features
- Automatically adds a reading time badge above single posts
- Shortcode: `[reading_time]`
- Translation ready

## Installation
1. Copy `reading-time-badge.php` into `wp-content/plugins/reading-time-badge/`
2. Activate the plugin from the WordPress admin
